Privacy Policy – TabMarkList

最終更新: 2026年8月27日 / Last updated: August 27, 2026

Chrome 拡張機能 TabMarkList（開発: KawaNova）のプライバシーポリシーです。

日本語

TabMarkList は、開いているタブのタイトルと URL から Markdown のリンク一覧を作り、ユーザーの操作でクリップボードへコピーする拡張です。Pro 機能の解除には Gumroad のライセンスキーを使います。

1. 収集する情報

  • 開いているタブのタイトルと URL（ウェブ履歴に相当）: コピー時に Chrome の tabs API で読みます。閲覧履歴 API は使いません。ページ本文・画像・Cookie は読みません。
  • ライセンスキー（認証情報）: Pro 解除のためにユーザーが入力した Gumroad ライセンスキーです。氏名・メールアドレス・住所・パスワードは拡張から収集しません。支払い（カード番号など）は Gumroad の購入ページで行われ、拡張は受け取りません。
  • 端末内の設定: Pro 解除済みかどうかとライセンスキーを chrome.storage.local に保存します。

2. 利用目的

タイトルと URL は Markdown 一覧の生成と、ユーザー操作によるクリップボードへの書き込みだけに使います。ライセンスキーは Pro 上限の解除判定だけに使います。広告・プロファイリング・与信・融資には使いません。

3. 共有（第三者への送信）

タイトルと URL は外部へ送りません。端末内だけで使い、コピー先はユーザーのクリップボードです。

ライセンスキーは、検証のためだけに https://api.gumroad.com/v2/licenses/verify へ HTTPS で送ります（商品 ID または permalink も付与します）。Gumroad の取り扱いは Gumroad Privacy Policy に従います。開発者（KawaNova）のサーバーへユーザーデータを送る機能はありません。データを販売しません。

4. 権限

  • tabs: 開いているタブのタイトルと URL を読み、Markdown 一覧を作るため。
  • clipboardWrite: ユーザーがコピーを押したとき、生成した Markdown をクリップボードへ書くため。
  • storage: Pro 解除状態とライセンスキーを端末内に保存するため。
  • https://api.gumroad.com/*: ライセンス検証 API を呼ぶため。

5. 保管と削除

データはユーザーの Chrome プロファイル内（chrome.storage.local）にあります。拡張を削除するか、Chrome のサイトデータ削除で消えます。開発者が遠隔から個別ユーザーのデータを閲覧・削除する仕組みはありません。

6. Chrome Web Store Limited Use

TabMarkList は Chrome ウェブストアのユーザーデータポリシー（Limited Use）に従います。権限で得たデータは、タブ一覧の Markdown 化とライセンス検証に必要な範囲だけ使います。広告・リターゲティング・与信判定には使いません。人間がユーザーのタブ一覧やライセンスキーを読む運用はありません。

7. お問い合わせ

本ポリシーに関する質問は、商品ページ kawadev6.gumroad.com/l/tabmarklist または kawa.dev.acc0unt@gmail.com まで。

English

TabMarkList is a Chrome extension that builds a Markdown link list from open tab titles and URLs, and copies it to the clipboard when the user asks. Pro features are unlocked with a Gumroad license key.

1. Data we handle

  • Open tab titles and URLs (web history): read via the Chrome tabs API on copy. The extension does not use the browsing history API, and does not read page bodies, images, or cookies.
  • License key (authentication): the Gumroad key the user types to unlock Pro. The extension does not collect name, email, address, or passwords. Payment card data is entered on Gumroad’s checkout, not in the extension.
  • Local settings: Pro unlock state and the license key are stored in chrome.storage.local.

2. How we use it

Titles and URLs are used only to build Markdown and write it to the clipboard after a user click. The license key is used only to decide whether Pro limits apply. We do not use this data for ads, profiling, creditworthiness, or lending.

3. Sharing

Titles and URLs are not sent off the device. They stay local except for the user’s clipboard.

The license key is sent over HTTPS only to https://api.gumroad.com/v2/licenses/verify, with product id or permalink, to verify the purchase. See the Gumroad Privacy Policy. The extension does not send user data to a KawaNova server. We do not sell user data.

4. Permissions

  • tabs: read open tab titles and URLs to build the Markdown list.
  • clipboardWrite: write the Markdown to the clipboard when the user clicks Copy.
  • storage: save Pro unlock state and the license key on the device.
  • https://api.gumroad.com/*: call the license verification API.

5. Retention and deletion

Data lives in the user’s Chrome profile (chrome.storage.local). Uninstalling the extension or clearing Chrome site data removes it. The developer cannot remotely view or delete an individual user’s data.

6. Chrome Web Store Limited Use

TabMarkList complies with the Chrome Web Store User Data Policy, including Limited Use. Permission-derived data is used only for Markdown tab lists and license verification. It is not used for ads, retargeting, or credit decisions. Humans do not read users’ tab lists or license keys in the course of operating the product.
