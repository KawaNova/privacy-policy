Privacy Policy – 書き置き (Sidejot)

最終更新: 2026年9月27日 / Last updated: September 27, 2026

Chrome 拡張機能「書き置き」（英語表示名 Sidejot、開発: KawaNova）のプライバシーポリシーです。見ているページの横に、必要なときだけ Markdown メモを残します。新しいタブは置き換えません。

日本語

1. 収集する情報

  • メモ本文: ユーザーが書いた文章、「取り込み」で選んだ文、「ページ」で読み取った本文です。chrome.storage.local に保存します。
  • ページのタイトルと URL（ウェブ履歴に相当）: 「取り込み」「ページ」、または右クリックの「メモに残す」を押したときだけ、そのタブのタイトルと URL をメモへ残します。閲覧履歴 API は使いません。ページを開いただけでは読みません。
  • ウェブサイトのコンテンツ: 「取り込み」は選択した文字だけを読みます。「ページ」は、メニューや広告を除くよう努めた本文を、ボタンを押したときだけ読みます。常時の監視はしません。
  • ライセンスキー（認証情報）: Pro 解除のためにユーザーが入力した Gumroad のライセンスキーです。氏名・メールアドレス・住所・パスワードは拡張から収集しません。支払い（カード番号など）は Gumroad の購入ページで行われ、拡張は受け取りません。
  • 選んだファイル: 「開く」「保存」は、ユーザーが選んだファイルだけを読み書きします。ファイルの中身は開発者のサーバーへ送りません。

2. 利用目的

メモ、タイトル、URL、選択文字、本文は、そのメモを端末内に残し、ユーザーが選んだファイルへ書くためだけに使います。ライセンスキーは Pro 解除の判定だけに使います。広告・プロファイリング・与信・融資には使いません。

3. 共有（第三者への送信）

メモ本文、タイトル、URL、選択文字、ページ本文、ファイルの中身は外部へ送りません。

ライセンスキーは、検証のためだけに https://api.gumroad.com/v2/licenses/verify へ HTTPS で送ります（商品 ID も付与します）。Gumroad の取り扱いは Gumroad Privacy Policy に従います。開発者（KawaNova）のサーバーへユーザーデータを送る機能はありません。データを販売しません。目的外に転送しません。

4. 権限

  • storage: メモ、Pro の状態、ライセンスキーを端末内に保存するため。
  • sidePanel: ツールバーのアイコンを押したときだけメモを開くため。
  • contextMenus: 選択文字を右クリックでメモに残すため。
  • scripting と http / https のホスト権限: 「取り込み」または「ページ」を押したタブの文字を読むため。それ以外のタブは読みません。
  • https://api.gumroad.com/*: ライセンス検証 API を呼ぶため。

リモートコードは使いません。Gumroad へのライセンス検証はリモートコードではありません。

5. 保管と削除

メモとライセンスキーはユーザーの Chrome プロファイル内（chrome.storage.local）にあります。選んだファイルを同じ場所へ上書きするための参照は、端末内の IndexedDB にあります。拡張を削除するか、Chrome の拡張機能データを消すと、端末内のメモは消えます。ユーザーが「保存」したパソコン上のファイルは、拡張を消しても残り、一覧からメモを外してもそのファイルは消えません。開発者が遠隔から個別ユーザーのデータを閲覧・削除する仕組みはありません。

6. Chrome Web Store Limited Use

書き置きは Chrome ウェブストアのユーザーデータポリシー（Limited Use）に従います。権限で得たデータは、メモを残すこととライセンス検証に必要な範囲だけ使います。広告・リターゲティング・与信判定には使いません。人間がユーザーのメモやライセンスキーを読む運用はありません。

English

Sidejot (Japanese display name: 書き置き) is a Chrome extension by KawaNova. It keeps a Markdown note beside the page you are reading, only when you open it. It does not replace the new tab page.

1. Data we handle

  • Note text: what you type, text you clip, and article text from Page. Stored in chrome.storage.local.
  • Page title and URL (web history): saved into the note only when you use Clip, Page, or the right-click “Save selection” command. The extension does not use the browsing history API, and it does not read a tab merely because it is open.
  • Website content: Clip reads only the selection. Page reads article text, and tries to leave out menus and ads, only after you press the button. It does not watch pages continuously.
  • License key (authentication): the Gumroad key you type to unlock Pro. The extension does not collect name, email, address, or passwords. Payment card data is entered on Gumroad’s checkout, not in the extension.
  • Files you choose: Open and Save read or write only the file you pick. File contents are not uploaded to the developer.

2. How we use it

Notes, titles, URLs, selections, and article text are used only to keep that memo on the device and to write a file you choose. The license key is used only to decide whether Pro is unlocked. We do not use this data for ads, profiling, creditworthiness, or lending.

3. Sharing

Note text, titles, URLs, selections, page content, and file contents are not sent off the device.

The license key is sent over HTTPS only to https://api.gumroad.com/v2/licenses/verify, with the product id, to verify the purchase. See the Gumroad Privacy Policy. The extension does not send user data to a KawaNova server. We do not sell user data, and we do not transfer it for unrelated purposes.

4. Permissions

  • storage: save notes, Pro state, and the license key on the device.
  • sidePanel: open the memo only when the toolbar icon is clicked.
  • contextMenus: save a selection from the right-click menu.
  • scripting and http / https host access: read text on the tab where you pressed Clip or Page. Other tabs are not read.
  • https://api.gumroad.com/*: call the license verification API.

The extension does not use remote code. The Gumroad license request is not remote code.

5. Retention and deletion

Notes and the license key live in the user’s Chrome profile (chrome.storage.local). A local IndexedDB entry remembers the file you chose so Save can overwrite that same file. Uninstalling the extension, or clearing its data, removes the on-device notes. A file you saved on disk remains if you uninstall the extension or remove a note from the list. The developer cannot remotely view or delete an individual user’s data.

6. Chrome Web Store Limited Use

Sidejot complies with the Chrome Web Store User Data Policy, including Limited Use. Permission-derived data is used only to keep notes and to verify a license. It is not used for ads, retargeting, or credit decisions. Humans do not read users’ notes or license keys in the course of operating the product.
