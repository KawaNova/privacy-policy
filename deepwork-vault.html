Privacy Policy – DeepWork Vault

Last updated: August 2026

DeepWork Vault ("the Extension") is a Chrome browser extension that provides a Pomodoro timer and website blocker to help users improve productivity.

1. Data We Collect

The Extension does not collect, store, or transmit any personal information to external servers. All user data (such as the blocklist and timer settings) is stored locally in your browser using the Chrome Storage API and never leaves your device.

2. License Key Verification

If you choose to unlock the Pro version, the license key you enter is sent to the Gumroad API (api.gumroad.com) solely for the purpose of verifying your purchase. No other personal data is transmitted. The license key itself is stored locally in your browser after successful verification.

3. Permissions Used

  • storage: To save your blocklist and settings locally in the browser.
  • declarativeNetRequest / tabs: To block access to websites you have specified during focus sessions.
  • alarms: To run the Pomodoro timer accurately in the background.
  • notifications: To alert you when a focus session has completed.

4. Third-Party Services

The Extension uses the Gumroad API for license verification only. Please refer to Gumroad's Privacy Policy for details on how they handle data.

5. Data Sharing

We do not sell, trade, or transfer your data to any third parties.

6. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected on this page.
